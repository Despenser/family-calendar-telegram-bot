# Requirements Document

## Introduction

При создании события пользователь может выбрать тип события: семейное или персональное. В настоящее время для персонального события используется эмодзи замка 🔒, что создает неправильное визуальное представление. Персональное событие должно использовать эмодзи человека 👤, чтобы лучше отражать его назначение.

## Glossary

- **System**: Telegram-бот семейного календаря
- **Personal_Event**: Событие, видимое только создателю
- **Family_Event**: Событие, видимое всем членам семьи
- **Event_Type_Selection_Keyboard**: Inline-клавиатура для выбора типа события при создании

## Requirements

### Requirement 1: Исправление эмодзи персонального события

**User Story:** Как пользователь, я хочу видеть эмодзи человека 👤 для персональных событий вместо замка 🔒, чтобы визуальное представление лучше отражало назначение события.

#### Acceptance Criteria

1. WHEN пользователь создает новое событие и видит клавиатуру выбора типа события, THEN THE System SHALL отображать кнопку "👤 Персональное событие" вместо "🔒 Персональное событие"
2. WHEN пользователь выбирает персональное событие, THEN THE System SHALL корректно обработать выбор и создать персональное событие
3. WHEN система отображает существующие персональные события в любом контексте, THEN THE System SHALL использовать эмодзи 👤 для обозначения персонального события
