# План реализации: Исправление парсинга callback-данных при удалении вложений

## Обзор

Данный план описывает пошаговую реализацию исправления бага в методе `handle()` класса `AttachmentCallbackHandler`. Исправление заключается в корректном парсинге callback-данных для составных действий (confirm/cancel + delete).

## Задачи

- [x] 1. Рефакторинг метода handle() для корректного парсинга составных действий
  - Изменить логику парсинга eventId для составных действий (confirm, cancel)
  - Убрать преждевременное извлечение eventId из parts[1] в начале метода
  - Переместить извлечение eventId внутрь каждого case блока
  - Исправить позиции извлечения eventId и attachmentId для действий confirm и cancel
  - Добавить детальное логирование процесса парсинга
  - _Requirements: 1.1, 1.2, 1.3, 2.1, 2.2, 2.3, 4.3, 4.4_

## Примечания

- Задачи, помеченные `*`, являются опциональными и могут быть пропущены для более быстрого MVP
- Каждая задача ссылается на конкретные требования для отслеживаемости

- Unit-тесты валидируют конкретные примеры и граничные случаи
