# Документ требований: Удаление сообщения о настройке автоматических напоминаний

## Введение

Данная спецификация описывает удаление автоматического сообщения "✅ Автоматически настроены напоминания: накануне, за 1 час, за 15 минут", которое отправляется пользователю после создания события. Это сообщение создает лишний шум в чате и не несет критической информации для пользователя.

## Глоссарь

- **Система**: Существующее Spring Boot приложение семейного календарь-бота
- **EventService**: Сервис для управления событиями
- **handleEventCreated**: Метод в EventService, который обрабатывает создание события и отправляет сообщение о напоминаниях
- **TelegramMessageService**: Сервис для отправки сообщений в Telegram

## Требования

### Требование 1

**Пользовательская история:** Как член семьи, я не хочу получать дополнительные сообщения после создания события, чтобы чат оставался чистым и не загроможденным.

#### Критерии приемки

1. WHEN пользователь создает событие с датой и временем, THEN Система НЕ ДОЛЖНА отправлять сообщение "✅ Автоматически настроены напоминания: накануне, за 1 час, за 15 минут"
2. WHEN пользователь создает событие без времени, THEN Система НЕ ДОЛЖНА отправлять сообщение "ℹ️ Добавьте время события для автоматических напоминаний"
3. WHEN все напоминания пропущены (событие слишком скоро), THEN Система НЕ ДОЛЖНА отправлять сообщение "ℹ️ Событие слишком скоро, автоматические напоминания не созданы"
4. WHEN событие создано, THEN Система ДОЛЖНА создавать автоматические напоминания без отправки уведомления пользователю
5. WHEN метод handleEventCreated вызывается, THEN Система НЕ ДОЛЖНА вызывать telegramMessageService.sendMessage()

### Требование 2

**Пользовательская история:** Как разработчик, я хочу сохранить логирование создания напоминаний, чтобы отслеживать работу системы.

#### Критерии приемки

1. WHEN Система создает автоматические напоминания, THEN Система ДОЛЖНА логировать event_id и количество созданных напоминаний с уровнем INFO
2. WHEN Система пропускает создание напоминания из-за времени, THEN Система ДОЛЖНА логировать причину с уровнем DEBUG
3. WHEN происходит ошибка создания напоминаний, THEN Система ДОЛЖНА логировать полный stack trace с уровнем ERROR
4. WHEN метод handleEventCreated выполняется, THEN Система ДОЛЖНА сохранить все существующие логи
5. WHEN удаляется отправка сообщений, THEN Система НЕ ДОЛЖНА удалять логирование
