# Требования: Актуализация команд /start и /help

## Введение

Семейный Календарь Бот предоставляет широкий функционал для управления событиями, но текущие команды /start и /help не отражают полный набор возможностей. Необходимо актуализировать эти команды, добавив все доступные команды и организовав их по категориям для улучшения пользовательского опыта.

## Глоссарий

- **System** - Telegram бот семейного календаря
- **User** - пользователь Telegram, взаимодействующий с ботом
- **Command** - текстовая команда, начинающаяся с символа "/"
- **Category** - логическая группа команд по функциональному назначению
- **Inline Keyboard** - встроенная клавиатура с кнопками под сообщением
- **MarkdownV2** - формат разметки текста в Telegram
- **Authorized User** - пользователь, зарегистрированный в системе и принадлежащий семье

## Требования

### Requirement 1

**User Story:** Как пользователь, я хочу видеть актуальный список всех доступных команд при вызове /help, чтобы понимать полный функционал бота.

#### Acceptance Criteria

1. WHEN пользователь отправляет команду /help THEN the System SHALL отобразить все доступные команды, включая /today, /week, /search, /filter, /stats, /trash
2. WHEN команды отображаются в /help THEN the System SHALL группировать команды по категориям для улучшения читаемости
3. WHEN пользователь не авторизован THEN the System SHALL помечать команды, требующие авторизации, эмодзи "🔒"
4. WHEN пользователь авторизован THEN the System SHALL отображать все команды с тематическими эмодзи без замков
5. WHEN команды отображаются THEN the System SHALL использовать кликабельный формат без моноширинного форматирования

### Requirement 2

**User Story:** Как пользователь, я хочу видеть команды, организованные по категориям, чтобы быстро находить нужную функцию.

#### Acceptance Criteria

1. WHEN команды группируются THEN the System SHALL создать категорию "📅 Просмотр событий" с командами /today, /week, /upcoming_events
2. WHEN команды группируются THEN the System SHALL создать категорию "➕ Управление событиями" с командами /add_event, /my_events
3. WHEN команды группируются THEN the System SHALL создать категорию "🔍 Поиск и фильтрация" с командами /search, /filter
4. WHEN команды группируются THEN the System SHALL создать категорию "📊 Статистика и корзина" с командами /stats, /trash
5. WHEN команды группируются THEN the System SHALL создать категорию "ℹ️ Справка" с командами /help, /start

### Requirement 3

**User Story:** Как пользователь, я хочу видеть актуальное приветственное сообщение при вызове /start, чтобы понимать основные возможности бота.

#### Acceptance Criteria

1. WHEN пользователь отправляет команду /start THEN the System SHALL отобразить обновленный список основных команд, включая новые команды
2. WHEN отображаются основные команды в /start THEN the System SHALL показать команды из всех категорий для полного представления о функционале
3. WHEN пользователь зарегистрирован THEN the System SHALL отобразить минимум 8 основных команд, представляющих все категории функционала
4. WHEN пользователь не зарегистрирован THEN the System SHALL отобразить информацию о необходимости регистрации и доступных после нее возможностях
5. WHEN команды отображаются в /start THEN the System SHALL использовать кликабельный формат для удобства использования

### Requirement 4

**User Story:** Как пользователь, я хочу видеть описания команд, соответствующие их текущему функционалу, чтобы правильно их использовать.

#### Acceptance Criteria

1. WHEN команда /today отображается THEN the System SHALL показать описание "Показать события на сегодня"
2. WHEN команда /week отображается THEN the System SHALL показать описание "Показать события на неделю (7 дней)"
3. WHEN команда /search отображается THEN the System SHALL показать описание "Поиск событий по тексту"
4. WHEN команда /filter отображается THEN the System SHALL показать описание "Фильтрация событий по типу"
5. WHEN команда /stats отображается THEN the System SHALL показать описание "Статистика событий за месяц"
6. WHEN команда /trash отображается THEN the System SHALL показать описание "Корзина удаленных событий"
7. WHEN команда /upcoming_events отображается THEN the System SHALL показать описание "Показать планы на 30 дней"

### Requirement 5

**User Story:** Как пользователь, я хочу, чтобы команда /add_event оставалась первой в списке основных команд, чтобы быстро создавать события.

#### Acceptance Criteria

1. WHEN основные команды отображаются в /start THEN the System SHALL размещать команду /add_event первой в списке
2. WHEN команды группируются по категориям в /help THEN the System SHALL сохранять логическую группировку, но выделять /add_event как основную команду
3. WHEN пользователь просматривает список команд THEN the System SHALL обеспечить видимость команды /add_event как приоритетной для создания событий

### Requirement 6

**User Story:** Как пользователь, я хочу видеть корректное форматирование MarkdownV2 во всех сообщениях, чтобы текст отображался правильно.

#### Acceptance Criteria

1. WHEN сообщения формируются THEN the System SHALL корректно экранировать все специальные символы MarkdownV2
2. WHEN команды отображаются THEN the System SHALL использовать метод escape() для экранирования текста команд
3. WHEN заголовки отображаются THEN the System SHALL использовать метод bold() для выделения заголовков
4. WHEN дополнительная информация отображается THEN the System SHALL использовать метод italic() для вспомогательного текста
5. WHEN сообщение содержит эмодзи THEN the System SHALL корректно обрабатывать эмодзи без нарушения форматирования
