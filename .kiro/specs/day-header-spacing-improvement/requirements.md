# Requirements Document

## Introduction

Данная спецификация описывает улучшение форматирования списков событий в командах `/week` и `/upcoming_events` путем добавления визуального отступа между заголовком дня и первым событием в списке.

## Glossary

- **System**: Telegram бот семейного календаря
- **EventFormatter**: Утилитный класс для форматирования событий
- **Day_Header**: Заголовок дня в формате "📍 26.01 (сегодня - понедельник)" или "🔜 27.01 (завтра - вторник)"
- **Event_List**: Список событий, отображаемых под заголовком дня
- **Visual_Spacing**: Пустая строка между заголовком дня и первым событием

## Requirements

### Requirement 1: Добавление визуального отступа после заголовка дня

**User Story:** Как пользователь, я хочу видеть визуальный отступ между заголовком дня и первым событием, чтобы список был более читаемым и структурированным.

#### Acceptance Criteria

1. WHEN команда `/week` отображает события THEN THE System SHALL добавить пустую строку после заголовка дня и перед первым событием
2. WHEN команда `/upcoming_events` отображает события THEN THE System SHALL добавить пустую строку после заголовка дня и перед первым событием
3. WHEN метод `formatDayHeader` форматирует заголовок дня THEN THE System SHALL включить дополнительный символ новой строки в конец заголовка
4. WHEN отображается несколько дней с событиями THEN THE System SHALL применить визуальный отступ для каждого заголовка дня
5. WHEN между днями есть разделитель THEN THE System SHALL сохранить существующее форматирование разделителей без изменений
