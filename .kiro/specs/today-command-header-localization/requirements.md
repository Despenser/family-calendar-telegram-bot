# Документ требований

## Введение

Данный документ описывает требования к исправлению формата заголовка команды `/today` для обеспечения корректной локализации дня недели на русский язык и использования дефиса вместо скобок в соответствии с форматом других команд.

Текущая проблема: заголовок команды `/today` отображается в формате "📅 События на сегодня (25.01.2026 (Sunday))", где день недели выводится на английском языке и используются вложенные скобки.

Ожидаемый формат: "📅 События на сегодня (25.01.2026 - Воскресенье)", где день недели на русском языке и используется дефис для разделения.

## Глоссарий

- **TodayCommandHandler**: Обработчик команды `/today`, показывающий события на текущий день
- **DateTimeFormatter**: Класс Java для форматирования дат и времени
- **Locale**: Настройка локали для форматирования дат на определенном языке
- **Command Header**: Заголовок команды, отображающий название команды и дополнительную информацию

## Требования

### Требование 1

**User Story:** Как пользователь, я хочу видеть день недели в заголовке команды `/today` на русском языке, чтобы информация была понятной и соответствовала языку интерфейса.

#### Критерии приемки

1. WHEN пользователь выполняет команду `/today` THEN система SHALL отображать день недели в заголовке на русском языке
2. WHEN система форматирует дату в заголовке THEN система SHALL использовать русскую локаль для форматирования дня недели
3. WHEN система отображает заголовок команды THEN система SHALL использовать формат "ДД.ММ.ГГГГ - День_недели" с дефисом в качестве разделителя
4. WHEN система отображает полный заголовок команды THEN система SHALL использовать формат "📅 События на сегодня (ДД.ММ.ГГГГ - День_недели)"

### Требование 2

**User Story:** Как разработчик, я хочу использовать единообразный формат даты во всех командах, чтобы обеспечить консистентность пользовательского интерфейса.

#### Критерии приемки

1. WHEN система форматирует дату с днем недели THEN система SHALL использовать паттерн "dd.MM.yyyy - EEEE"
2. WHEN система создает DateTimeFormatter THEN система SHALL указывать русскую локаль (Locale.forLanguageTag("ru"))
3. WHEN система форматирует дату THEN система SHALL обеспечивать правильное склонение дня недели на русском языке
