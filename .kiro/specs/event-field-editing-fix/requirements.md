# Requirements Document

## Introduction

Данный документ описывает требования к исправлению функции редактирования полей событий в Telegram боте семейного календаря. В настоящее время при попытке редактирования любого поля события (название, дата, время, описание) пользователь получает сообщение "Неизвестное поле для редактирования". Проблема заключается в некорректной обработке callback data в методе `handleEditField` класса `EventCallbackHandler`.

## Glossary

- **Event**: Событие в календаре, содержащее название, дату, время и описание
- **Callback_Data**: Строка данных, передаваемая при нажатии inline-кнопки в Telegram
- **EventCallbackHandler**: Обработчик callback queries для операций с событиями
- **Field**: Поле события (title, date, time, description)
- **Payload**: Часть callback data после префикса

## Requirements

### Requirement 1: Корректное извлечение имени поля из callback data

**User Story:** Как пользователь, я хочу редактировать поля событий, чтобы обновлять информацию в календаре.

#### Acceptance Criteria

1. WHEN пользователь нажимает кнопку редактирования поля события THEN система SHALL корректно извлечь имя поля из callback data формата `edit_field_{field}_{eventId}`
2. WHEN callback data имеет формат `edit_field_title_{eventId}` THEN система SHALL извлечь значение "title"
3. WHEN callback data имеет формат `edit_field_date_{eventId}` THEN система SHALL извлечь значение "date"
4. WHEN callback data имеет формат `edit_field_time_{eventId}` THEN система SHALL извлечь значение "time"
5. WHEN callback data имеет формат `edit_field_description_{eventId}` THEN система SHALL извлечь значение "description"

### Requirement 2: Отображение соответствующего сообщения для каждого поля

**User Story:** Как пользователь, я хочу видеть понятные инструкции при редактировании каждого поля, чтобы знать, что мне нужно сделать.

#### Acceptance Criteria

1. WHEN пользователь выбирает редактирование названия THEN система SHALL отобразить сообщение "📝 Редактирование названия\n\nОтправьте новое название события:"
2. WHEN пользователь выбирает редактирование даты THEN система SHALL отобразить сообщение "📅 Редактирование даты\n\nВыберите новую дату из календаря:"
3. WHEN пользователь выбирает редактирование времени THEN система SHALL отобразить сообщение "🕐 Редактирование времени\n\nВыберите новое время:"
4. WHEN пользователь выбирает редактирование описания THEN система SHALL отобразить сообщение "📄 Редактирование описания\n\nОтправьте новое описание события:"
5. WHEN система получает некорректное имя поля THEN система SHALL отобразить сообщение "❌ Неизвестное поле для редактирования"

### Requirement 3: Логирование процесса редактирования

**User Story:** Как разработчик, я хочу видеть логи процесса редактирования полей, чтобы отслеживать работу системы и диагностировать проблемы.

#### Acceptance Criteria

1. WHEN пользователь начинает редактирование поля THEN система SHALL записать в лог информацию о пользователе, поле и eventId
2. WHEN происходит ошибка при извлечении поля THEN система SHALL записать в лог детали ошибки с уровнем ERROR
3. WHEN поле успешно извлечено THEN система SHALL записать в лог имя поля с уровнем DEBUG

### Requirement 4: Обработка ошибок при парсинге callback data

**User Story:** Как пользователь, я хочу получать понятные сообщения об ошибках, чтобы понимать, что пошло не так.

#### Acceptance Criteria

1. WHEN callback data имеет некорректный формат THEN система SHALL обработать ошибку и отобразить сообщение об ошибке
2. WHEN eventId в callback data не является числом THEN система SHALL обработать ошибку и записать её в лог
3. WHEN происходит исключение при обработке callback THEN система SHALL использовать аннотацию @HandleCallbackErrors для обработки ошибки
