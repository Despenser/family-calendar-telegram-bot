# Implementation Plan: Event Field Editing Fix

## Overview

Данный план описывает пошаговую реализацию исправления функции редактирования полей событий. Основная задача - модифицировать метод `handleEditField` в классе `EventCallbackHandler` для корректного извлечения имени поля из callback data формата `edit_field_{field}_{eventId}`.

  - Добавить валидацию формата (проверка количества частей)
  - Добавить обработку NumberFormatException при парсинге eventId
  - Добавить детальное логирование процесса извлечения
  - Установить состояние редактирования через ConversationStateService
