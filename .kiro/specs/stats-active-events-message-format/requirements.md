# Requirements Document

## Introduction

Изменение формата сообщения о количестве активных событий в команде /stats для улучшения читаемости и единообразия стиля.

## Glossary

- **Stats_Command**: Команда /stats, которая отображает статистику событий за текущий месяц
- **Active_Events_Message**: Сообщение, отображающее количество активных событий в текущем месяце
- **Message_Format**: Формат текстового сообщения, отправляемого пользователю

## Requirements

### Requirement 1

**User Story:** Как пользователь, я хочу видеть информацию о количестве активных событий в более лаконичном формате, чтобы сообщение было легче читать.

#### Acceptance Criteria

1. WHEN пользователь выполняет команду /stats и имеет активные события, THEN THE Stats_Command SHALL отображать сообщение в формате "Активных событий в этом месяце - {count}"
2. WHEN количество активных событий равно 0, THEN THE Stats_Command SHALL отображать сообщение "Все события этого месяца завершены! 🎉"
3. WHEN общее количество событий равно 0, THEN THE Stats_Command SHALL отображать сообщение "В этом месяце нет событий. Создайте первое событие с помощью /add_event"
4. WHEN сообщение формируется, THEN THE Stats_Command SHALL применять italic форматирование к тексту сообщения
5. WHEN сообщение содержит специальные символы Markdown, THEN THE Stats_Command SHALL корректно экранировать их
