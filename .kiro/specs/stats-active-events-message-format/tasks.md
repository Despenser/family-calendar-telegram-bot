# Implementation Plan: Изменение формата сообщения о активных событиях в /stats

## Overview

Изменение формата сообщения о количестве активных событий в команде /stats с "У вас {count} активных событий в этом месяце" на "Активных событий в этом месяце - {count}".

## Tasks

- [x] 1. Изменить формат сообщения в StatsCommandHandler
  - Найти строку с форматированием сообщения о активных событиях
  - Изменить формат с "У вас %d активных событий в этом месяце" на "Активных событий в этом месяце - %d"
  - Убедиться, что italic форматирование применяется корректно
  - _Requirements: 1.1, 1.4_

- [ ]* 2. Обновить unit-тесты в StatsCommandHandlerTest
  - Найти тесты, проверяющие формат сообщения о активных событиях
  - Обновить ожидаемые значения в тестах на новый формат
  - Убедиться, что тесты для других сценариев (нет событий, все завершены) остаются корректными
  - _Requirements: 1.1, 1.2, 1.3, 1.4_

- [x] 3. Checkpoint - Убедиться, что все тесты проходят
  - Запустить все тесты проекта

  - Спросить пользователя, если возникнут вопросы
