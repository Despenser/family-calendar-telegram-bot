# Implementation Plan: Исправление ошибки при включении напоминаний

## Overview

Исправление LazyInitializationException при включении автоматических напоминаний. Проблема возникает из-за того, что User загружается как lazy proxy и не инициализируется вне транзакции. Решение: добавить метод `findByIdWithUser` в EventRepository с eager загрузкой User через @EntityGraph.
