# План реализации: Расширенное форматирование результатов поиска

## Обзор

Этот план описывает шаги по добавлению специального формата отображения событий для команды `/search` с полной информацией о каждом событии, включая дату и тип. Это обеспечит пользователям лучшую ориентацию в найденных событиях.

  - Добавить строку с типом события "👨‍👩‍👧‍👦 Тип: Семейное" или "👤 Тип: Личное"
