# Требования: Исправление подсчета событий в команде /my_events

## Введение

При использовании команды `/my_events` в шапке отображается неверное количество событий. После редактирования события количество в шапке не соответствует фактическому количеству отображаемых событий. Например, показывается "Всего событий: 5", хотя отображается только 2 события.

Проблема заключается в том, что метод `getActiveEventsCount` считает все события, кроме удаленных (статус НЕ `DELETED`), включая черновики (`DRAFT`) и завершенные события (`COMPLETED`). При этом команда `/my_events` отображает только события со статусом `ACTIVE`.

## Глоссарий

- **Event** - событие в календаре
- **EventStatus** - статус события (ACTIVE, DRAFT, COMPLETED, DELETED)
- **Active Event** - активное событие со статусом ACTIVE
- **Draft Event** - черновик события со статусом DRAFT
- **Completed Event** - завершенное событие со статусом COMPLETED
- **Deleted Event** - удаленное событие со статусом DELETED
- **EventService** - сервис для управления событиями
- **EventRepository** - репозиторий для доступа к событиям в базе данных
- **MyEventsCommandHandler** - обработчик команды /my_events
- **BotMessageBuilder** - построитель сообщений бота

## Требования

### Требование 1

**User Story:** Как пользователь, я хочу видеть корректное количество событий в шапке команды /my_events, чтобы понимать, сколько у меня активных событий.

#### Acceptance Criteria

1. WHEN система подсчитывает события для шапки "Мои события" THEN система SHALL учитывать только события со статусом ACTIVE
2. WHEN пользователь вызывает команду /my_events THEN система SHALL отображать в шапке количество, равное количеству отображаемых событий
3. WHEN пользователь редактирует событие THEN система SHALL обновлять шапку с корректным количеством активных событий
4. WHEN система обновляет сообщение первого события после редактирования THEN система SHALL использовать корректный подсчет активных событий
5. WHEN система передает флаг isMyEventsHeader следующему событию после удаления THEN система SHALL использовать корректный подсчет активных событий
