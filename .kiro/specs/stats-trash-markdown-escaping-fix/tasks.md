# План реализации: Исправление экранирования MarkdownV2 в командах /stats и /trash

## Обзор

Исправление ошибок парсинга MarkdownV2 в командах `/stats` и `/trash` путем правильного использования методов `MarkdownFormatter`. Замена `formatMessage()` с отформатированными аргументами на прямую конкатенацию методов `escape()`, `bold()`, `italic()`.

## Задачи

- [x] 1. Исправить форматирование в StatsCommandHandler
  - Заменить все вызовы `formatMessage()` с отформатированными аргументами на прямую конкатенацию
  - Использовать `escape()` для обычного текста, `bold()` для жирного, `italic()` для курсива
  - Убедиться, что все точки в обычном тексте экранируются через `escape()`
  - _Требования: 1.1, 1.2, 1.3, 1.4_

- [ ]* 1.1 Написать unit-тесты для StatsCommandHandler
  - Тест с нулевыми значениями статистики
  - Тест с ненулевыми значениями статистики
  - Проверить отсутствие неэкранированных точек в результате
  - Проверить корректное применение форматирования
  - _Требования: 1.1, 1.3, 1.4_

- [x] 2. Исправить форматирование в TrashCommandHandler
  - Заменить `formatMessage()` в методе `handle()` на прямую конкатенацию

  - Убедиться, что длинный текст в курсиве корректно форматируется через `italic()`
  - _Требования: 2.1, 2.2, 2.3, 2.4_

- [ ]* 2.1 Написать unit-тесты для TrashCommandHandler
  - Тест сообщения о пустой корзине

- [x] 3. Контрольная точка - проверка исправлений

- Задачи, отмеченные `*`, являются опциональными и могут быть пропущены для более быстрой реализации MVP
