# Requirements Document

## Introduction

Данная спецификация описывает исправление функциональности включения/отключения напоминаний для событий в Telegram боте семейного календаря. В текущей реализации при нажатии кнопок "🔕 Отключить напоминания" и "🔔 Включить напоминания" пользователь видит только всплывающее уведомление (callback query answer), но само сообщение события не обновляется с новой клавиатурой. Это создает впечатление, что действие не выполнилось, и пользователь не может повторно включить/отключить напоминания.

## Glossary

- **Event_Message**: Сообщение в Telegram чате, отображающее информацию о событии календаря
- **Reminder_Toggle_Button**: Inline-кнопка для включения или отключения автоматических напоминаний
- **Callback_Query**: Запрос от Telegram API при нажатии на inline-кнопку
- **Message_Update**: Операция редактирования существующего сообщения в Telegram чате
- **Keyboard_Refresh**: Обновление inline-клавиатуры сообщения с актуальным состоянием кнопок
- **ReminderCallbackHandler**: Компонент, обрабатывающий callback queries для управления напоминаниями
- **TelegramMessageService**: Сервис для отправки и редактирования сообщений в Telegram
- **KeyboardService**: Сервис для создания inline-клавиатур
- **BotMessageBuilder**: Компонент для формирования текста сообщений о событиях

## Requirements

### Requirement 1: Обновление сообщения при отключении напоминаний

**User Story:** Как пользователь, я хочу видеть обновленное сообщение события после отключения напоминаний, чтобы понимать, что действие выполнено успешно и иметь возможность включить напоминания обратно.

#### Acceptance Criteria

1. WHEN пользователь нажимает кнопку "🔕 Отключить напоминания" THEN THE System SHALL обновить сообщение события с новой клавиатурой, содержащей кнопку "🔔 Включить напоминания"
2. WHEN сообщение события обновляется после отключения напоминаний THEN THE System SHALL сохранить весь текст сообщения без изменений
3. WHEN сообщение события обновляется после отключения напоминаний THEN THE System SHALL заменить кнопку "🔕 Отключить напоминания" на кнопку "🔔 Включить напоминания"
4. IF обновление сообщения не удается THEN THE System SHALL залогировать предупреждение и продолжить выполнение
5. WHEN отключение напоминаний завершается THEN THE System SHALL отправить callback query answer с подтверждением "✅ Напоминания отключены"

### Requirement 2: Обновление сообщения при включении напоминаний

**User Story:** Как пользователь, я хочу видеть обновленное сообщение события после включения напоминаний, чтобы понимать, что действие выполнено успешно и иметь возможность отключить напоминания при необходимости.

#### Acceptance Criteria

1. WHEN пользователь нажимает кнопку "🔔 Включить напоминания" THEN THE System SHALL обновить сообщение события с новой клавиатурой, содержащей кнопку "🔕 Отключить напоминания"
2. WHEN сообщение события обновляется после включения напоминаний THEN THE System SHALL сохранить весь текст сообщения без изменений
3. WHEN сообщение события обновляется после включения напоминаний THEN THE System SHALL заменить кнопку "🔔 Включить напоминания" на кнопку "🔕 Отключить напоминания"
4. IF обновление сообщения не удается THEN THE System SHALL залогировать предупреждение и продолжить выполнение
5. WHEN включение напоминаний завершается THEN THE System SHALL отправить callback query answer с информацией о созданных напоминаниях

### Requirement 3: Корректная работа с messageId

**User Story:** Как разработчик, я хочу, чтобы система корректно обрабатывала случаи, когда messageId недоступен, чтобы избежать ошибок при обновлении сообщений.

#### Acceptance Criteria

1. WHEN messageId равен null THEN THE System SHALL пропустить обновление сообщения и продолжить выполнение
2. WHEN messageId доступен THEN THE System SHALL использовать его для обновления сообщения события
3. IF обновление сообщения выбрасывает исключение THEN THE System SHALL залогировать предупреждение с деталями ошибки
4. WHEN обновление сообщения не удается THEN THE System SHALL не прерывать выполнение основной операции (отключение/включение напоминаний)

### Requirement 4: Логирование операций

**User Story:** Как разработчик, я хочу иметь детальное логирование операций включения/отключения напоминаний, чтобы легко диагностировать проблемы в production.

#### Acceptance Criteria

1. WHEN начинается обработка отключения напоминаний THEN THE System SHALL залогировать debug сообщение с eventId
2. WHEN начинается обработка включения напоминаний THEN THE System SHALL залогировать debug сообщение с eventId
3. WHEN сообщение события успешно обновлено THEN THE System SHALL залогировать debug сообщение с eventId и messageId
4. IF обновление сообщения не удается THEN THE System SHALL залогировать warning с eventId, messageId и деталями ошибки
5. WHEN операция завершается успешно THEN THE System SHALL залогировать info сообщение с eventId и количеством созданных/удаленных напоминаний

### Requirement 5: Отсутствие дополнительных сообщений при создании события

**User Story:** Как пользователь, я не хочу получать отдельное сообщение о создании напоминаний при создании события, чтобы чат не был загроможден лишними сообщениями.

#### Acceptance Criteria

1. WHEN создаются автоматические напоминания при создании нового события THEN THE System SHALL не отправлять отдельное сообщение в чат
2. WHEN создаются автоматические напоминания при создании нового события THEN THE System SHALL включить информацию о напоминаниях только в основное сообщение события
3. WHEN пользователь включает напоминания через кнопку "🔔 Включить напоминания" THEN THE System SHALL обновить только сообщение события без отправки дополнительных сообщений
4. WHEN пользователь отключает напоминания через кнопку "🔕 Отключить напоминания" THEN THE System SHALL обновить только сообщение события без отправки дополнительных сообщений

### Requirement 6: Порядок кнопок в клавиатуре события

**User Story:** Как пользователь, я хочу, чтобы кнопка "Завершить" была в нижней части клавиатуры, чтобы случайно не завершить событие при попытке управления напоминаниями.

#### Acceptance Criteria

1. WHEN формируется клавиатура события с активными напоминаниями THEN THE System SHALL расположить кнопку "🔕 Отключить напоминания" выше кнопки "✅ Завершить"
2. WHEN формируется клавиатура события без активных напоминаний THEN THE System SHALL расположить кнопку "🔔 Включить напоминания" выше кнопки "✅ Завершить"
3. WHEN формируется клавиатура события THEN THE System SHALL расположить кнопку "✅ Завершить" в самом низу клавиатуры
4. WHEN обновляется клавиатура после включения/отключения напоминаний THEN THE System SHALL сохранить порядок кнопок согласно новому состоянию напоминаний
