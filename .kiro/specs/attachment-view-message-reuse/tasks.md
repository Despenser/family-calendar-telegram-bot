# План реализации: Переиспользование сообщения при просмотре вложения

## Обзор

Данный план описывает пошаговую реализацию механизма переиспользования сообщений при просмотре вложений. Вместо создания нового сообщения при просмотре вложения, система будет удалять текущее сообщение, отправлять файл и сохранять его messageId для последующего редактирования.
