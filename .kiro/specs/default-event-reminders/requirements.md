# Документ требований: Автоматические напоминания по умолчанию

## Введение

Данная спецификация описывает реализацию системы автоматических напоминаний по умолчанию для событий в семейном календарь-боте. В настоящее время пользователи должны вручную настраивать напоминания для каждого события. Новая функциональность будет автоматически создавать набор напоминаний при создании события с учетом часового пояса пользователя, что значительно улучшит пользовательский опыт.

## Глоссарь

- **Система**: Существующее Spring Boot приложение семейного календарь-бота
- **Автоматическое напоминание**: Напоминание, создаваемое системой автоматически при создании события без участия пользователя
- **Напоминание по умолчанию**: Предустановленный набор типов напоминаний, которые создаются автоматически
- **Часовой пояс пользователя**: Значение поля `timezone` в таблице `users`, используемое для расчета времени напоминаний
- **Event**: Событие в календаре
- **Reminder**: Сущность напоминания о событии
- **ReminderService**: Сервис для управления напоминаниями
- **EventService**: Сервис для управления событиями
- **User**: Пользователь системы с настройками часового пояса

## Требования

### Требование 1

**Пользовательская история:** Как член семьи, я хочу автоматически получать напоминания о созданных событиях, чтобы не настраивать их вручную каждый раз.

#### Критерии приемки

1. WHEN пользователь создает событие с датой и временем, THEN Система ДОЛЖНА автоматически создать набор напоминаний по умолчанию
2. WHEN событие создано, THEN Система ДОЛЖНА создать напоминание "Вечером накануне" (20:00 предыдущего дня)
3. WHEN событие создано, THEN Система ДОЛЖНА создать напоминание "За 1 час до события"
4. WHEN событие создано, THEN Система ДОЛЖНА создать напоминание "За 15 минут до события"
5. WHEN напоминания созданы, THEN Система ДОЛЖНА показать сообщение "✅ Автоматически настроены напоминания: накануне, за 1 час, за 15 минут"

### Требование 2

**Пользовательская история:** Как член семьи, я хочу, чтобы напоминания рассчитывались с учетом моего часового пояса, чтобы получать уведомления в правильное время.

#### Критерии приемки

1. WHEN Система рассчитывает время напоминания "Вечером накануне", THEN Система ДОЛЖНА использовать часовой пояс создателя события
2. WHEN Система рассчитывает время напоминания "За 1 час", THEN Система ДОЛЖНА вычесть 1 час от времени начала события в часовом поясе создателя
3. WHEN Система рассчитывает время напоминания "За 15 минут", THEN Система ДОЛЖНА вычесть 15 минут от времени начала события в часовом поясе создателя
4. WHEN напоминание отправляется, THEN Система ДОЛЖНА конвертировать reminder_time в часовой пояс получателя для отображения
5. WHEN пользователь просматривает напоминания, THEN Система ДОЛЖНА показывать время в его часовом поясе

### Требование 3

**Пользовательская история:** Как член семьи, я хочу иметь возможность отключить автоматические напоминания, чтобы настраивать их вручную при необходимости.

#### Критерии приемки

1. WHEN пользователь создает событие, THEN Система ДОЛЖНА показать inline-кнопку "🔕 Без автоматических напоминаний"
2. WHEN пользователь нажимает кнопку отключения, THEN Система ДОЛЖНА удалить все автоматически созданные напоминания
3. WHEN автоматические напоминания отключены, THEN Система ДОЛЖНА показать кнопку "🔔 Настроить напоминания вручную"
4. WHEN пользователь нажимает кнопку ручной настройки, THEN Система ДОЛЖНА показать меню выбора типов напоминаний
5. WHEN пользователь настраивает напоминания вручную, THEN Система НЕ ДОЛЖНА создавать автоматические напоминания

### Требование 4

**Пользовательская история:** Как член семьи, я хочу редактировать автоматически созданные напоминания, чтобы настроить их под свои нужды.

#### Критерии приемки

1. WHEN пользователь просматривает событие с автоматическими напоминаниями, THEN Система ДОЛЖНА показать кнопку "🔔 Изменить напоминания"
2. WHEN пользователь нажимает кнопку изменения, THEN Система ДОЛЖНА показать список текущих напоминаний с возможностью удаления
3. WHEN пользователь удаляет напоминание, THEN Система ДОЛЖНА удалить его из базы данных
4. WHEN пользователь добавляет новое напоминание, THEN Система ДОЛЖНА создать его с учетом часового пояса пользователя
5. WHEN изменения сохранены, THEN Система ДОЛЖНА показать обновленный список напоминаний

### Требование 5

**Пользовательская история:** Как член семьи, я хочу, чтобы автоматические напоминания не создавались для событий без времени, так как для них невозможно точно рассчитать время уведомления.

#### Критерии приемки

1. WHEN пользователь создает событие только с датой (без времени), THEN Система НЕ ДОЛЖНА создавать автоматические напоминания
2. WHEN событие без времени создано, THEN Система ДОЛЖНА показать сообщение "ℹ️ Добавьте время события для автоматических напоминаний"
3. WHEN пользователь добавляет время к событию без времени, THEN Система ДОЛЖНА предложить создать автоматические напоминания
4. WHEN пользователь соглашается, THEN Система ДОЛЖНА создать стандартный набор напоминаний
5. WHEN событие имеет только дату, THEN Система ДОЛЖНА показать кнопку "🔔 Настроить напоминания вручную"

### Требование 6

**Пользовательская история:** Как член семьи, я хочу, чтобы напоминание "За 15 минут" не создавалось для событий, которые начинаются менее чем через 15 минут, чтобы избежать немедленной отправки.

#### Критерии приемки

1. WHEN пользователь создает событие, начинающееся менее чем через 15 минут, THEN Система НЕ ДОЛЖНА создавать напоминание "За 15 минут"
2. WHEN пользователь создает событие, начинающееся менее чем через 1 час, THEN Система НЕ ДОЛЖНА создавать напоминание "За 1 час"
3. WHEN пользователь создает событие на сегодня, THEN Система НЕ ДОЛЖНА создавать напоминание "Вечером накануне"
4. WHEN Система пропускает создание напоминания, THEN Система ДОЛЖНА создать только применимые напоминания
5. WHEN все напоминания пропущены, THEN Система ДОЛЖНА показать сообщение "ℹ️ Событие слишком скоро, автоматические напоминания не созданы"

### Требование 7

**Пользовательская история:** Как разработчик, я хочу иметь конфигурируемый набор напоминаний по умолчанию, чтобы легко изменять его в будущем.

#### Критерии приемки

1. WHEN приложение запускается, THEN Система ДОЛЖНА загружать конфигурацию напоминаний по умолчанию из application.yml
2. WHEN конфигурация содержит список типов напоминаний, THEN Система ДОЛЖНА использовать их для автоматического создания
3. WHEN конфигурация содержит флаг enabled, THEN Система ДОЛЖНА включать/отключать автоматические напоминания глобально
4. WHEN конфигурация изменяется, THEN Система ДОЛЖНА применять новые настройки после перезапуска
5. WHEN конфигурация отсутствует, THEN Система ДОЛЖНА использовать значения по умолчанию (EVENING_BEFORE, ONE_HOUR_BEFORE, FIFTEEN_MINUTES_BEFORE)

### Требование 8

**Пользовательская история:** Как член семьи, я хочу получать уведомления о напоминаниях в моем часовом поясе, чтобы видеть правильное локальное время.

#### Критерии приемки

1. WHEN Система отправляет уведомление о напоминании, THEN Система ДОЛЖНА форматировать время события в часовом поясе получателя
2. WHEN уведомление содержит время напоминания, THEN Система ДОЛЖНА показывать его в часовом поясе получателя
3. WHEN члены семьи находятся в разных часовых поясах, THEN Система ДОЛЖНА отправлять уведомления с временем в соответствующем часовом поясе каждого
4. WHEN пользователь изменяет свой часовой пояс, THEN Система ДОЛЖНА пересчитать время отображения для будущих уведомлений
5. WHEN reminder_time хранится в базе данных, THEN Система ДОЛЖНА хранить его в UTC для единообразия

### Требование 9

**Пользовательская история:** Как член семьи, я хочу видеть индикатор автоматических напоминаний при просмотре события, чтобы знать, что уведомления настроены.

#### Критерии приемки

1. WHEN пользователь просматривает событие с автоматическими напоминаниями, THEN Система ДОЛЖНА показать эмодзи "🔔" рядом с названием события
2. WHEN пользователь просматривает детали события, THEN Система ДОЛЖНА показать раздел "Напоминания" со списком настроенных напоминаний
3. WHEN напоминания отсутствуют, THEN Система ДОЛЖНА показать текст "Напоминания не настроены"
4. WHEN напоминания настроены вручную, THEN Система ДОЛЖНА показать эмодзи "🔔" и пометку "(настроено вручную)"
5. WHEN напоминания настроены автоматически, THEN Система ДОЛЖНА показать эмодзи "🔔" и пометку "(автоматически)"

### Требование 10

**Пользовательская история:** Как разработчик, я хочу логировать создание автоматических напоминаний, чтобы отслеживать работу системы и диагностировать проблемы.

#### Критерии приемки

1. WHEN Система создает автоматические напоминания, THEN Система ДОЛЖНА логировать event_id и количество созданных напоминаний с уровнем INFO
2. WHEN Система пропускает создание напоминания из-за времени, THEN Система ДОЛЖНА логировать причину с уровнем DEBUG
3. WHEN происходит ошибка создания напоминаний, THEN Система ДОЛЖНА логировать полный stack trace с уровнем ERROR
4. WHEN автоматические напоминания отключены пользователем, THEN Система ДОЛЖНА логировать event_id с уровнем INFO
5. WHEN автоматические напоминания отключены глобально, THEN Система ДОЛЖНА логировать это при запуске с уровнем WARN

### Требование 11

**Пользовательская история:** Как член семьи, я хочу, чтобы автоматические напоминания создавались для повторяющихся событий, чтобы получать уведомления о каждом вхождении.

#### Критерии приемки

1. WHEN пользователь создает повторяющееся событие, THEN Система ДОЛЖНА создать напоминания только для первого вхождения
2. WHEN наступает время следующего вхождения, THEN Система ДОЛЖНА автоматически создать напоминания для него
3. WHEN повторяющееся событие редактируется, THEN Система ДОЛЖНА пересчитать напоминания для будущих вхождений
4. WHEN повторяющееся событие удаляется, THEN Система ДОЛЖНА удалить все напоминания для будущих вхождений
5. WHEN пользователь отключает автоматические напоминания для повторяющегося события, THEN Система НЕ ДОЛЖНА создавать их для будущих вхождений

### Требование 12

**Пользовательская история:** Как член семьи, я хочу, чтобы напоминание "За 15 минут" было добавлено в систему вместо "За 10 минут".

#### Критерии приемки

1. WHEN Система создает автоматические напоминания, THEN Система ДОЛЖНА поддерживать тип FIFTEEN_MINUTES_BEFORE
2. WHEN пользователь выбирает напоминание вручную, THEN Система ДОЛЖНА показать опцию "За 15 минут до события"
3. WHEN напоминание "За 15 минут" создается, THEN Система ДОЛЖНА рассчитать reminder_time как event_time - 15 минут
4. WHEN напоминание "За 15 минут" отправляется, THEN Система ДОЛЖНА включить текст "За 15 минут до события" в уведомление
5. WHEN существующий тип TEN_MINUTES_BEFORE больше не используется, THEN Система ДОЛЖНА заменить его на FIFTEEN_MINUTES_BEFORE

### Требование 13

**Пользовательская история:** Как член семьи, я хочу отключать напоминания для конкретного события, чтобы не получать уведомления о событиях, которые мне не важны.

#### Критерии приемки

1. WHEN пользователь просматривает событие с напоминаниями, THEN Система ДОЛЖНА показать кнопку "🔕 Отключить все напоминания"
2. WHEN пользователь нажимает кнопку отключения, THEN Система ДОЛЖНА удалить все напоминания для этого события
3. WHEN напоминания отключены, THEN Система ДОЛЖНА показать сообщение "✅ Напоминания отключены для этого события"
4. WHEN пользователь отключает напоминания, THEN Система ДОЛЖНА показать кнопку "🔔 Включить напоминания"
5. WHEN пользователь включает напоминания обратно, THEN Система ДОЛЖНА создать стандартный набор автоматических напоминаний

### Требование 14

**Пользовательская история:** Как член семьи, я хочу получать уведомления с разным текстом в зависимости от времени отправки и полной информацией о событии, чтобы понимать, о каком событии идет речь и когда оно наступит.

#### Критерии приемки

1. WHEN Система отправляет напоминание "Вечером накануне", THEN Система ДОЛЖНА включить текст "🌙 Напоминание: завтра в [время] у вас событие **[название события]**"
2. WHEN Система отправляет напоминание "За 1 час", THEN Система ДОЛЖНА включить текст "⏰ Напоминание: через 1 час начнется событие **[название события]** ([дата] в [время])"
3. WHEN Система отправляет напоминание "За 15 минут", THEN Система ДОЛЖНА включить текст "⚡ Напоминание: через 15 минут начнется событие **[название события]** ([время])"
4. WHEN уведомление содержит описание события, THEN Система ДОЛЖНА включать его после названия (с обрезкой до 100 символов)
5. WHEN уведомление содержит время события, THEN Система ДОЛЖНА форматировать его в часовом поясе получателя
6. WHEN событие является персональным, THEN Система ДОЛЖНА добавить эмодзи "👤" перед названием
7. WHEN событие является семейным, THEN Система ДОЛЖНА добавить эмодзи "👨‍👩‍👧‍👦" перед названием
