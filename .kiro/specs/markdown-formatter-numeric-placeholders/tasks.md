# План реализации: Поддержка числовых плейсхолдеров в MarkdownFormatter

## Обзор

Модификация метода `MarkdownFormatter.formatMessage()` для поддержки всех стандартных плейсхолдеров Java путём делегирования форматирования `String.format()` с последующим экранированием результата. Реализация включает обновление метода, добавление property-based тестов и обеспечение обратной совместимости.
