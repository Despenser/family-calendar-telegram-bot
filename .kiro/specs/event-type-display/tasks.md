# План реализации: Отображение типа события

## Обзор

Реализация добавления отображения типа события в сообщениях бота. Изменения затрагивают только класс `BotMessageBuilder` и его тесты. Все задачи выполняются инкрементально с проверкой корректности на каждом шаге.

## Задачи

- [x] 1. Обновить метод buildEventMessage для отображения типа события
  - Добавить константы для текстов типов событий
  - Добавить логику определения типа события (обработка null)
  - Вставить строку с типом между временем и описанием
  - Применить экранирование через MarkdownFormatter.escape()
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 2.1, 4.1_

- [ ]* 1.1 Написать unit-тесты для отображения типа события
  - Тест для семейного события (isPersonal = false)
  - Тест для персонального события (isPersonal = true)
  - Тест для события с null значением isPersonal
  - Тест для события без описания (тип - последняя строка)
  - Тест для проверки порядка строк в сообщении
  - _Requirements: 1.2, 1.3, 1.4, 3.2, 3.3, 4.1_

- [ ]* 1.2 Написать property-тест для семейных событий

## Примечания

- Задачи, помеченные `*`, являются опциональными и могут быть пропущены для более быстрого MVP
- Каждая задача ссылается на конкретные требования для отслеживаемости
- Property-тесты проверяют универсальные свойства корректности
- Unit-тесты проверяют конкретные примеры и граничные случаи
- Минимум 100 итераций для каждого property-теста
