# План реализации: Фильтрация прошедшего времени при выборе

## Обзор

Реализация проактивной фильтрации прошедшего времени при выборе даты и времени для событий. Вместо показа ошибки после выбора, система будет отображать только доступные часы и минуты с учетом timezone пользователя.

## Примечания

- Задачи, помеченные `*`, являются опциональными и могут быть пропущены для более быстрой реализации MVP
- Каждый property-based тест должен выполняться минимум 100 итераций
- Все property-based тесты должны быть помечены комментарием: `// Feature: time-selection-past-filtering, Property {number}: {property_text}`
- Используется библиотека jqwik для property-based тестирования
