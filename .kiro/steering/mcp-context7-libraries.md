# Правило использования MCP Context7 для библиотек

**ВАЖНО: Всегда используй MCP Context7 для получения актуальной информации о библиотеках.**

- Перед использованием любой библиотеки или фреймворка проверяй актуальную документацию через Context7
- Получай свежие сведения о версиях, API и best practices через Context7
- Используй Context7 для проверки совместимости библиотек
- При возникновении вопросов о конфигурации или использовании библиотек обращайся к Context7
- Проверяй через Context7 актуальность примеров кода и рекомендаций

## Когда использовать Context7:
- При добавлении новых зависимостей в проект
- При обновлении существующих библиотек
- При решении проблем с интеграцией библиотек
- При поиске информации о новых возможностях библиотек
- При проверке deprecated методов и их замен
